The safety warning label that should come printed on every human being — one line, 140 characters, funny first and plausible second. It reads like a real printed label ("WARNING: Do not shake..."), piles up two painfully specific numbers (37 unfinished projects, 214 unread emails), and lands the laugh in the last word: the firm plan to fix everything on Monday... probably.

## Run it

```sh
python3 entry/main.py
```

This writes the label to `/output/entry.txt` with no trailing newline.
